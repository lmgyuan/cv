# Yuan Yuan — CV

This repository hosts my CV as a PDF using GitHub Pages.

The homepage opens `cv.pdf` directly. If automatic navigation is unavailable, it provides a link to the PDF.

## Updating the CV

Replace `cv.pdf` with the latest exported PDF, keeping the filename unchanged, then commit and push to `main`. GitHub Pages publishes the update at the same address.

## Hosting

In **Settings → Pages**, publish from the `main` branch and the `/(root)` folder.
